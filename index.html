01Gesturefy for Chrome · 鼠标手势扩展移植

已上架 Chrome 网上应用店 商店评分 5.0 296 位用户 GPL-3.0 · 保留原作者版权

原 Gesturefy 是 Firefox 独占的鼠标手势扩展。这个移植版把它带到 Chrome 并成功上架： 按住鼠标左 / 中 / 右键划出手势即可执行命令，80+ 内置命令覆盖标签页、导航、滚动、 缩放、复制粘贴等。这是我用户量最大的作品。

技术要点
  • 起点是一个缺口：Gesturefy 只有 Firefox 版，Chrome 用户用不上鼠标手势 → 移植并适配 Chrome 的 Manifest 与权限模型（权限按需申请）JavaScript · Rollup · WebExtensions
  • 关键取舍：不重建久经验证的核心手势引擎，新功能（如双击关闭标签页）以独立内容脚本模块挂载，优先保证"不把原有功能改坏"
  • 降低上手成本：内置微软 Edge 官方 16 手势映射，Edge 用户可一键迁移；补齐简体 / 繁体中文界面与隐私政策页
上架信息
版本 1.4.0，2026 年 8 月更新；安装包 282 KB；商店声明不收集任何数据（无服务器、无统计、无遥测）。

02PY查价助手 · Steam 比价扩展

已上架 Chrome 网上应用店 210 位用户 Manifest V3

在 Steam 商店详情页和愿望单上，直接显示第三方市场（SteamPy）的比价面板， 按版本（标准版 / 豪华版 / 终极版 / DLC）分行列出代购价与 CDKey 价， 方便判断"现在买还是等折扣"。

技术要点
  • 起点是一个麻烦：想买游戏时要在 Steam 和比价站之间来回切换 → 直接在商店页与愿望单注入比价面板JavaScript · Manifest V3 · Service Worker
  • 安全取舍：Content Script 不直接发请求，统一委托 Background 代理，并做域名白名单校验，收敛越权请求面
  • 刻意克制：只在点击「PY查价」时才请求、不读 Cookies、不后台常驻——宁可多一次点击，也不冒被风控拦截的风险

03网页 Steam 双开 · 多账号容器隔离

已上架 Firefox Add-ons MPL-2.0

利用 Firefox 原生容器技术（Contextual Identities），为每个 Steam 账号建立物理隔离的 Cookie 环境，在一个浏览器窗口里同时登录多个账号，互不干扰。

技术要点
  • 起点是一个限制：同一个浏览器没法同时登录两个 Steam 账号 → 用 Firefox 原生容器（Contextual Identities）为每个账号建立独立 Cookie 环境JavaScript · WebExtensions · browser.storage.local
  • 安全底线：零凭证接触——扩展只负责隔离环境，不读取、不记录、不保存任何账号密码
  • 数据只在本地：账号备注、PIN 锁、排序全部存 browser.storage.local，不上传服务器

04小米手环心率悬浮卡片

已发布免安装 exe 24 个测试用例全通过 Windows · GPL-3.0

把小米手环的实时心率投到 Windows 桌面悬浮卡片上：数字 + 心电图波形 + 设备昵称。 打恐怖游戏或健身游戏时开着，随时能看到自己心率。

技术要点
  • 起点是一个需求：打恐怖游戏 / 健身游戏时想实时看到自己心率 → 订阅手环的标准心率广播，做成桌面悬浮卡片Python · PyQt6 · 蓝牙 BLE · PyInstaller
  • 两个关键取舍：① 点击穿透，让鼠标事件直达游戏；② 透明度只作用于背景与描边并保留一个最低不透明度——因为 Windows 会把完全透明的窗口判定为"无可点击内容"，追求视觉上全透反而会让整张卡片失去交互
  • 交付形态：打包成单文件免安装 exe，手环端只需打开"心率广播"这一项设置

05Hermes 无痕模式 · AI Agent 会话不留痕

MIT 开源 多轮交叉审计

一个让 AI Agent 会话结束后不在本机留下痕迹的方案，采用四层纵深防御架构： 策略层封锁持久化写入、运行时护栏、框架层会话隔离、会话结束后反向审计与安全擦除。

技术要点
  • 起点是一个矛盾：AI Agent 用起来方便，但会话结束后会在本机留下日志、缓存与临时文件 → 用四层纵深防御把"不留痕"做成可验证的流程Python · Shell · 插件式日志过滤器
  • 关键设计：写入全部限定在时间戳沙箱；日志在内存层就完成脱敏（明文不落盘）；向量库用哨兵文件跳过敏感会话
  • 最难的一环是"到底清干净没有" → 用 10 步以上反向审计加安全覆写擦除逐项验证，并在文档里写明做不到的部分
