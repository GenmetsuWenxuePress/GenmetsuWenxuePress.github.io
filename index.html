01Gesturefy for Chrome · 鼠标手势扩展移植

已上架 Chrome 网上应用店 商店评分 5.0 296 位用户 GPL-3.0 · 保留原作者版权

原 Gesturefy 是 Firefox 独占的鼠标手势扩展。这个移植版把它带到 Chrome 并成功上架： 按住鼠标左 / 中 / 右键划出手势即可执行命令，80+ 内置命令覆盖标签页、导航、滚动、 缩放、复制粘贴等。这是我用户量最大的作品。

技术要点
  • 保留原扩展的手势识别引擎，Chrome 侧重新适配 Manifest 与权限模型（权限按需申请）
  • 模块化架构：新增功能（如双击关闭标签页）以独立的内容脚本模块放在 core/extras/，经 manifest 挂载；冻结的核心 content.bundle.js 不重建，避免改坏久经验证的逻辑
  • 内置微软 Edge 官方 16 手势映射，Edge 用户可一键迁移
  • 80+ 内置命令、摇杆手势（左右键互按）、滚轮手势、自定义用户脚本
  • 三语言界面（English / 简体中文 / 繁體中文）与独立隐私政策页
技术栈
JavaScript、Rollup 打包、WebExtensions、Chrome Manifest 适配
上架信息
版本 1.4.0，2026 年 8 月更新；安装包 282 KB；商店声明不收集任何数据（无服务器、无统计、无遥测）。
说明
移植 / 衍生作品（原作者 Robbendebiene，GPL-3.0），完整保留原始版权声明，不冒认原创。

02PY查价助手 · Steam 比价扩展

已上架 Chrome 网上应用店 210 位用户 Manifest V3

在 Steam 商店详情页和愿望单上，直接显示第三方市场（SteamPy）的比价面板， 按版本（标准版 / 豪华版 / 终极版 / DLC）分行列出代购价与 CDKey 价， 方便判断"现在买还是等折扣"。

技术要点
  • Manifest V3；Content Script 不直接发请求，统一委托 Background（Service Worker）代理，规避 CORS 限制
  • Background 侧做域名白名单校验（仅允许目标站点），收敛越权请求面
  • 按需查询：仅在点击「PY查价」按钮时才发起请求，减少被风控拦截
  • 防抖处理 Steam 新版动态愿望单的超长列表，滚动不卡顿
  • 不收集用户信息、不读 Cookies、不后台常驻
技术栈
JavaScript、Manifest V3、Service Worker、Chrome Storage、防抖
说明
基于 2024 年官方版本的核心逻辑开发的第三方增强维护版（主要修复原版在新版浏览器与新版 Steam 网页上的兼容性问题），非官方发布。

03网页 Steam 双开 · 多账号容器隔离

已上架 Firefox Add-ons MPL-2.0

利用 Firefox 原生容器技术（Contextual Identities），为每个 Steam 账号建立物理隔离的 Cookie 环境，在一个浏览器窗口里同时登录多个账号，互不干扰。

技术要点
  • 基于 Firefox 原生 Contextual Identities 容器 API，为每个账号建立独立 Cookie 环境
  • 零凭证接触：扩展只管理隔离环境，不读取、不记录、不保存任何账号密码
  • 本地 PIN 码锁定账号列表；超长文本备注（悬浮查看，可记余额 / 密钥）；拖拽排序
  • 数据仅存 browser.storage.local，不上传任何服务器
  • 暗色 UI，对齐 Steam 客户端视觉风格
技术栈
JavaScript、WebExtensions、Contextual Identities API、browser.storage.local
说明
人机协作项目（原文声明）：整体想法与功能设计由我负责，具体代码生成由 Google Gemini 完成。

04小米手环心率悬浮卡片

已发布免安装 exe 24 个测试用例全通过 Windows · GPL-3.0

把小米手环的实时心率投到 Windows 桌面悬浮卡片上：数字 + 心电图波形 + 设备昵称。 打恐怖游戏或健身游戏时开着，随时能看到自己心率。

技术要点
  • 订阅标准心率服务 notify（服务 0x180D / 特征 0x2A37），8 秒无数据自动重连
  • 点击穿透让鼠标事件直达下层窗口（如游戏）
  • 透明度只作用于背景与描边，并把背景 alpha 钳制到最小 1——规避 Windows 判定"全透明窗口无可点击内容"导致的无法交互
  • 拖动位置钳制在屏幕内，防止窗口被拖出屏幕丢失；托盘图标 16px + 32px 双尺寸适配
  • 多设备卡片垂直堆叠；PyInstaller 打包单文件免安装 exe
技术栈
Python、PyQt6、蓝牙 BLE、PyInstaller
测试
24 个 pytest 用例覆盖配置迁移、心率区间与闪烁逻辑、多卡片布局、透明度像素级验证。

05Hermes 无痕模式 · AI Agent 会话不留痕

MIT 开源 多轮交叉审计

一个让 AI Agent 会话结束后不在本机留下痕迹的方案，采用四层纵深防御架构： 策略层封锁持久化写入、运行时护栏、框架层会话隔离、会话结束后反向审计与安全擦除。

技术要点
  • 四层纵深防御：能力矩阵封锁持久化写入 / 运行时护栏 / 会话级隔离标记 / 会话后反向审计
  • 写入全部限定在时间戳 TTL 沙箱；shell 历史抑制（HISTFILE=/dev/null）
  • 7 个缓存目录（web、截图、视频、图片、音频、文档、vision）符号链接进沙箱——崩溃也不留残留
  • 日志插件在内存层脱敏（明文不落盘），事后擦除兜底；向量库用哨兵文件细粒度跳过敏感会话
  • 会话结束后执行 10 步以上反向审计：残留检测 → os.urandom 覆写 → fsync → 截断 → 删除
技术栈
Python、Shell、插件式日志过滤器、向量索引哨兵、安全擦除
说明
文档中显式列出"做不到的部分"（操作系统层 swap / core dump、网络层代理与 API 提供方日志、 第三方 IDE 监听）——边界写清楚，比假装全能安全。仓库署名：幻灭文学出版社 + Hermes （多轮交叉审计）。
